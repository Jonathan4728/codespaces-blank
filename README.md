# Flores Small Engine Repair Website

This is a fast, mobile-friendly static website.

## Preview it

Open `index.html` in Google Chrome or Microsoft Edge.

## Before publishing

Search and replace these placeholders:

- `+10000000000` with your real phone number
- `your@email.com` with your real email address
- Update the service area if needed
- Adjust any service wording or prices you want displayed

The email address must be changed in both:

1. `index.html`
2. `script.js`

## Free hosting options

You can upload this folder to:

- GitHub Pages
- Cloudflare Pages
- Netlify

A custom domain is optional. You can build and test the whole website before paying for a domain.

## Files

- `index.html` — website content
- `styles.css` — colors, layout, and mobile design
- `script.js` — mobile menu and quote form
- `favicon.svg` — browser tab icon
